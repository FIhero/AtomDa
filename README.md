# Проект на основе книги "Атомные привычки"

## API эндпоинты

### Привычки
* `GET /api/habits/` - Список привычек текущего пользователя
* `POST /api/habits/` - Создание новой привычки
* `GET /api/habits/{id}/` - Получение конкретной привычки
* `PUT /api/habits/{id}/` - Обновление привычки
* `PATCH /api/habits/{id}/` - Частичное обновление привычки
* `DELETE /api/habits/{id}/` - Удаление привычки
* `GET /api/habits/public/` - Список публичных привычек

### Аутентификация
* `POST /api/token/` - Получение JWT токена (email + password)
* `POST /api/token/refresh/` - Обновление токена

### Пользователи
* `POST /api/users/register/` - Регистрация нового пользователя
* `GET /api/users/me/` - Профиль текущего пользователя
* `PUT /api/users/me/` - Обновление профиля
* `GET /api/users/` - Список всех пользователей (только админам)

### Документация
* `GET /swagger/` - Swagger UI документация
* `GET /redoc/` - ReDoc документация

# Приложение привычки
## Что здесь есть?
- При создании привычки автоматически регистрируется пользователь и время создания и/или обновления
- Можно написать место, время, периодичность выполнения, время на выполнение, что выполнить(действие), какая это привычка (приятная или нет), связанные привычки, публичность
- Есть список своих привычек и опубликованных
- Есть пагинация - максимум 5 привычек на страницу

### - Валидация
- Времени выполнения - не более 120 секунд
- Вознаграждение приятной привычки - его нет
- Связанные привычки - приятны
- Запрет на одновременную связь приятной и связанной привычки
- Периодичность - не более 7 дней


# Приложение пользователь
## Что здесь есть?
- Регистрация пользователя - указывается: почта, пароль, имя, фамилия, телефон, город
- Просмотр профиля пользователя
В профиле пользователя можно увидеть: id, почту, ФИ, телефон, город, аватар, дата создания, последний вход
- И просмотр списка пользователей для администраторов

### - Валидация
- Совпадение 2 паролей
